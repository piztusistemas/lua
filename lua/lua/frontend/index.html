Lua

Abre un proxecto para traballar: cada proxecto leva os seus formularios e os seus datos.

Este proxecto aínda non ten ferramentas. Crea o seu primeiro formulario: o asistente pode deseñalo a partir dun documento que xa teñas ou dunha descrición. Tamén lle podes engadir o cronograma ou as actas.

Opcións

Interface

LaTeX

Se o compilador escollido non consegue xerar o informe, Lua proba os outros que teñas instalados. Unha plantilla pode esixir o seu propio compilador.

Maxima (cálculo dos problemas)

Maxima calcula as fórmulas dos problemas (coma en Yang) e comproba as solucións da IA. Sen Maxima, Lua só calcula números e fórmulas simples.

Formatos de exportación

Os formatos desactivados desaparecen da barra de ferramentas da previsualización.

Asistente de IA (opcional)

Só se usa para crear plantillas (estilos) a partir dunha descrición, un documento de mostra ou unha páxina web. Sen clave, o resto de Lua funciona igual.

Canto pode chegar a escribir a IA nunha soa resposta. Súbeo se unha plantilla longa volve co erro de resposta cortada; o modelo escollido ten que admitir ese valor.

Aplícase en cada chamada. Por defecto 240 s. Súbeo a 600 s ou máis con modelos de razoamento lentos ou peticións longas.

Módulos

Lua descarga e actualiza Buxo automaticamente desde GitHub. Só se ofrece ao usuario cando hai unha clave de IA configurada.

Instalar LaTeX manualmente

Debian / Ubuntu:

sudo apt install texlive-latex-base texlive-latex-recommended texlive-pictures texlive-latex-extra texlive-xetex texlive-luatex poppler-utils

Fedora:

sudo dnf install texlive-latex texlive-collection-pictures texlive-xetex texlive-luatex poppler-utils

Arch:

sudo pacman -S texlive-core texlive-pictures poppler

Windows: MiKTeX · macOS: MacTeX

Despois de instalar, peche e volva abrir Lua para que o aviso desapareza.

Axustes do texto

Aplícase á previsualización e ao PDF. As fontes «do sistema» compílanse con xelatex. Se a plantilla ten deseño propio, mantén a súa fonte (só cambia o tamaño e o interliñado).
